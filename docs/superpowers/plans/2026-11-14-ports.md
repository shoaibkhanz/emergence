# Ports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Ports section in the Emergence sidebar listing every listening TCP server with the agent that owns it, and a
port card popup to open, inspect or stop one.

**Architecture:** `mods/ports/lib.js` holds every decision as pure functions over recorded `lsof`/`ps` text and Herdr's
`terminals()` (tested with `bun test`). `mods/ports/main.js` polls, calls lib, draws the section and opens the card.
`mods/port-card/main.js` is a dumb popup: everything arrives in props; it only refreshes its one process and does the
Stop recheck and kill. Part 2 (System, status bar) is a separate plan written after this ships.

**Tech Stack:** Herdr 0.1.15 mods (gpui-kit / gpui-base / herdr modules, JavaScript), `bun test`, macOS `lsof`/`ps`.

**Spec:** `docs/superpowers/specs/2026-11-14-ports-section-design.md` (Part 1 and "The shared piece").

## Global Constraints

- Work on branch `feat/ports`. Never push `main` mid-work: every push to `main` is what installed users' Update chip pulls.
- No `// DEBUG` comments, temporary `nextCommand` loops or probe file writes in any commit (CI greps for `// ?DEBUG`).
- Theme tokens only; Geist for text, Geist Mono (`const MONO = "Geist Mono"`) for ports, branches, paths, commands.
- Nothing animates; re-render only when the computed list changes.
- Named constants at the top of each file for every interval, size, threshold and table (no bare numbers in logic).
- Every `exec` gets `{ timeout: 4000 }`; a poll never starts while the previous one is in flight.
- Only terminals with `machine == null` (this computer) take part in ownership.
- Herdr doesn't see edits until a reload: `herdr-app do layout.switch --name main`, wait 1.5 s, `--name emergence`.
- Verify UI with `herdr-app shot <file>` and `herdr-app status`; never synthesize OS key or mouse events.
- Commit messages: `<type>: <description>`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Verified facts (2026-11-14, this Mac)

- `terminals()` entries carry `pid` (the shell), `foreground: { argv, cwd, name, pid }` (the agent), `machine`
  (`null` locally), `parent`, `program`, `state`, `address`.
- `lsof -nP -iTCP -sTCP:LISTEN -Fpcn` and `ps -axo ...` each take ~35 ms. `ps` `comm` is a full path with spaces.
- Popups: `openOverlay({ mod, kind: "popup", width, height, at, props })`; row-menu focuses itself in `init`.
- `cx.open_url(url)`, `cx.write_to_clipboard(text)` exist on the event `cx`.

## Placement (decided at planning)

"Working N" and the Settled shelf are drawn inside the inbox mod, at its foot. A `ports` layout block after `inbox`
therefore sits **below Working/Settled, above the Settings footer**, not between Inbox and Working as the approved
sketch showed. Moving Working out of inbox is a refactor this work doesn't need.

## Review Focus

1. An agent started in `~` (or a dotfiles repo at `~`) must not claim every orphan on the machine → Task 2 test.
2. A server started with `&`/`nohup` (parent pid 1) inside a live agent's worktree must show as that agent's, *probable*,
   never "no agent" amber → Task 2 test.
3. A pid reused between the card opening and Stop must not be killed → Task 3 `holds` test + Task 5 recheck.
4. A remote terminal whose pid equals a local pid must not claim the local process → Task 2 test.
5. `uvicorn --reload` (two pids holding one port in one tree) must be one row whose pid is the supervisor → Task 3 test.

### Task 2: Ownership

**Files:**
- Modify: `mods/ports/lib.js`, `mods/ports/lib.test.js`

**Interfaces:**
- Consumes: `Proc`, `parsePs` (Task 1).
- Produces:
  - `slug(path: string) -> string`: every char not `[A-Za-z0-9]` → `-`.
  - `scratchSlug(cwd: string) -> string | null`: the `<slug>` of `…/claude-<digits>/<slug>/…` when the path starts with
    `/tmp`, `/private/tmp`, `/var/folders` or `/private/var/folders`.
  - `ownerContext({ terminals, roots, home }) -> Ctx`: `terminals` is Herdr's `terminals()`; `roots` is
    `Map<string /* agent folder */, string | null /* git top-level, null if not a repo */>`. Ctx holds
    `byPid: Map<number, address>` (shell pid and foreground pid → address, live local terminals only), `fg: Set<number>`
    of agent foreground pids, and `areas: { root, exact: boolean, slug, address, seq }[]` for live local agent and shell
    terminals (root = git top-level, else the folder with `exact: true`; dropped when root is `home` or `/`).
  - `owner(pid: number, procs: Map<number, Proc>, cwd: string | undefined, ctx: Ctx) -> Owner`,
    `Owner = { kind: "sure" | "probable" | "docker" | "orphan", address: string | null }`.
    Order: walk `ppid` (stop at 1, missing, or 64 hops) → first `byPid` hit is `sure`; else comm basename matches
    `DOCKER = /^(com\.docker\.|vpnkit|OrbStack)/` → `docker`; else deepest `areas` root containing `cwd` (exact areas:
    equal only), tie → highest `seq`, → `probable`; else `scratchSlug(cwd)` equals an area's `slug` → `probable`;
    else `orphan`.

### Task 3: Servers (rows)

**Files:**
- Modify: `mods/ports/lib.js`, `mods/ports/lib.test.js`

**Interfaces:**
- Consumes: `Listener`, `Proc`, `Owner`, `owner`, `Ctx` (Tasks 1–2).
- Produces:
  - `urlFor(hosts: string[], port: number) -> string`: `*`/`0.0.0.0`/`[::]` present, or both `127.0.0.1` and
    `[::1]` → `http://localhost:<port>`; only `127.0.0.1` → `http://127.0.0.1:<port>`; only `[::1]` →
    `http://[::1]:<port>`; else `http://<first host>:<port>`.
  - `isWeb(port: number, comm: string) -> boolean`: false when `port` in
    `NOT_WEB_PORTS = [5432, 3306, 6379, 27017, 9229, 9230, 11211, 5672, 1883, 2181, 9092]` or comm basename in
    `NOT_WEB_NAMES = ["postgres", "mysqld", "redis-server", "mongod", "memcached"]`; true otherwise.
    Carries a `// ponytail:` comment: the table is the ceiling; a probe on the person's own click is the upgrade.
  - `servers({ listeners, procs, cwds, ctx, home }) -> Server[]`,
    `Server = { key: string /* `${pid}:${port}` */, pid, port, ports: number[] /* every port of pid, ascending */,
    command: string, hosts: string[], url: string, web: boolean, network: boolean, age: number, cwd: string | null,
    owner: Owner }`. Rules, in order:
    1. Group listeners by (pid, port); hosts merged.
    2. Drop a (pid, port) when an ancestor pid also holds that port (keep the topmost: Review Focus 5).
    3. Drop when `ctx.fg` has the pid and the owner terminal is an agent (the agent's own port).
    4. Keep owner kinds `sure`, `probable`, `docker`; keep `orphan` only when `cwd` is under `home` or a temp root and
       the comm basename is not in `AGENT_BINS = ["claude", "codex", "omp", "pi", "opencode"]` (`// ponytail:` comment).
    5. `network` = any host is `*`, `0.0.0.0`, `[::]` or not a loopback address.
  - `sortServers(list: Server[]) -> Server[]` (new array): owned (`sure`/`probable`/`docker`) by port ascending, then
    orphans by `age` descending.
  - `holds(listeners: Listener[], pid: number, port: number) -> boolean`.
  - `ago(seconds: number) -> string`: `now`, `12m`, `3h`, `2d` (as inbox's `ago`, in seconds).
